Metrics concepts

Four takes on showing real progress across a training cycle. All use the same fake 6-week double-progression cycle, so you are comparing the visuals, not the data.

Current direction

Scorecard + cycle snapshot

Concept A with the trajectory panel on top. Works for 4–12 week cycles; drawn from the real computeCycleSnapshot output.
A

Cycle scorecard

Grid of every lift × every week. Each square says how it progressed: more weight, more reps, held, slipped.
B

Rep-range ladder

Every set as a dot inside its target rep range. Shows the double-progression cycle itself.
C

Progress index

One graph for the whole cycle. Switch the metric between weight, reps, volume, and est. 1RM.
D

Set stack

One lift at a time, set by set. Anything new since last week is coloured — even a single extra rep.
